# Инструкции для агентов

Проект решает exact-span NER для `ORG`, `NAME` и `GEO`. Финальные `start` и  
`end` всегда относятся к исходной Python Unicode-строке; `end` не включается.

## Прочитать перед изменениями

1. `ner_uz_hackathon_participant/LABELING_GUIDE.md`
2. `ner_uz_hackathon_participant/API.md`
3. `docs/EXPERIMENT_PROTOCOL.md`
4. `docs/ARCHITECTURE.md`

## Обязательные правила

- Для среды, зависимостей и команд использовать `uv`; не использовать голый  
`pip` и не полагаться на глобальный Python.
- Полноценные модельные эксперименты запускать на GPU. Для этого выходи за sandbox, там cuda доступна. CPU допустим только для  
unit-тестов, проверки данных, конфигов и коротких smoke-тестов.
- Следовать KISS: выбирать самое простое решение, которое сохраняет корректные  
offsets, воспроизводимость и возможность честной абляции.
- Не создавать слишком большие файлы. Ориентир — до 300 строк; при смешении  
обязанностей разделить модуль раньше.
- Комментарии в коде писать на русском языке.
- У каждой функции и метода должен быть короткий русский docstring.
- Для структурированных данных и конфигураций использовать `dataclass`;  
не передавать неописанные словари между слоями проекта.
- Не изменять содержимое `ner_uz_hackathon_participant/`: это reference  
организаторов.
- Не нормализовать исходный текст на месте и не терять отображение к character  
offsets.
- Не дублировать data-, metric- и decoding-логику внутри реализаций моделей.
- Каждый эксперимент задавать конфигом и сохранять resolved config, data hashes,  
seed, версии окружения, метрики и предсказания.
- `best` выбирать по exact-span micro-F1; `last` сохранять для полного resume.
- Новая архитектура должна возвращать общий `Entity(label, start, end, score)`.
- Любое изменение поведения покрывать тестом. Обязательны проверки offsets,  
BIO/BIOES, chunk boundaries, decoding, exact-span метрик и API-контракта.
- Блокноты использовать только для EDA; воспроизводимая логика живёт в `src/`  
и `scripts/`.

## Стиль Python

Python 3.10+, type hints для публичных API, `pathlib.Path`, маленькие функции,  
явный поток данных и отсутствие скрытого глобального состояния. Форматирование  
и lint — Ruff, тесты — pytest.
