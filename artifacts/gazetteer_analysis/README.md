Checked on 2026-09-05 (Europe/Moscow).

## Data attribution

`raw/UZ.zip` and the derived `geonames_geo_aliases.csv` contain data from
[GeoNames](https://www.geonames.org/), licensed under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The downloaded licence/schema text is preserved in `raw/geonames_readme.txt`.
The snapshot URL, HTTP Last-Modified, retrieval timestamp and SHA-256 are in
`raw/UZ.snapshot.json`. The dump is supplied by GeoNames without accuracy or
completeness warranties.

Changes made: retain feature classes A/P/H/T/V/L, flatten names and alternative
names, discard names shorter than three normalized characters or without letters,
add normalized keys (NFKC, casefold, apostrophe unification, whitespace collapse),
preserve original spellings and object IDs. Language is unknown when absent in the
source. Script describes Latin/Cyrillic presence; `other` includes other scripts.
This derived dictionary has not been semantically validated.

## Files

- `sources.csv` / `sources.json`: formats, access, licences, scope and limitations
  for GeoNames, OSM, Wikidata, the state enterprise registry and Central Bank list.
- `geonames_geo_aliases.csv`: actual external GEO aliases; no dev-derived aliases.
- `summary.json`: reproducibility metadata, input hashes and aggregate statistics.
- `coverage.csv`: full gold-mention lexical coverage; not a NER model evaluation.
- `cross_label_collisions.csv`: GEO strings appearing as NAME/ORG in current data.
- `new_dev_geo_review.csv`: 25 extra dev forms for inspection only; do not use to
  extend the training lexicon. Copy this file before recording manual decisions:
  rerunning the audit regenerates it.
- `queries/*.rq`: unexecuted Wikidata query templates, each limited to 50 QIDs.
  Limits mean these are neither exhaustive extracts nor source-coverage estimates.

The full OSM, Wikidata and official organisation registries were not downloaded.
Their coverage values are intentionally not reported. OSM's ODbL and Wikidata's
CC0 are separate from the GeoNames licence; open redistribution terms for the
official organisation registry files were not confirmed.

From the project root run `uv run python scripts/eda/gazetteer_analysis.py` to recompute
locally. Add `--download` only if the initial GeoNames snapshot is missing.
The notebook section is reproducibly generated by
`scripts/build_gazetteer_section.py`; running that builder clears only section 5's
outputs, so execute those cells again afterwards.
