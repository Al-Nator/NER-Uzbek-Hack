## Две проверки

Скрипт: [`archive_a100_runs.py`](../scripts/archive_a100_runs.py).
После копирования выполняются два независимых чтения всех файлов на обоих
хостах с SHA-256; проверяются полный набор путей, размеры и содержимое.
Между проходами удалённый набор также должен оставаться неизменным.
Симлинки и изменения файла во время хэширования запрещены.

Отчёты `verification_1.json` и `verification_2.json` появляются только после
успешной проверки. Пока их нет, перенос не считается подтверждённым, удаление
не разрешено. Сам `--delete` в CLI аудита не выполняет удаление.

Служба `uzner-archive-a100.service` запускает
[`finish_a100_archive.py`](../scripts/finish_a100_archive.py): ждёт rsync и
старый watcher s47, выполняет обе полные проверки, затем ещё раз хэширует
remote перед очисткой. Удаляются только отдельные проверенные experiment-каталоги;
активное обучение блокирует очистку. Отсутствующие локальные канонические runs
публикуются из архива через hard links. Любое расхождение останавливает службу.
`deletion_complete.json` появляется только после фактического удаления всех
проверенных удалённых копий. Пока этого отчёта нет, очистка не объявляется завершённой.

```bash
journalctl --user -u uzner-archive-a100.service -f
```

```bash
uv run python scripts/archive_a100_runs.py \
  --archive artifacts/remote_archive/alnator_20260906_v1 --verify
```
