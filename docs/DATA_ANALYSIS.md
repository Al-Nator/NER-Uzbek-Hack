# Анализ данных

`data_analysis.ipynb` содержит EDA и сохранённые результаты разделов 1–5.
Открывайте ноутбук из корня репозитория. Используются неизменённые данные
`ner_uz_hackathon_participant/data/`; их SHA-256 совпадают с исходным анализом.

## Запуск

```bash
uv run --with jupyterlab --with ipywidgets --with pandas==2.3.3 --with transformers==5.14.1 --with sentencepiece==0.2.1 jupyter lab data_analysis.ipynb
uv run python scripts/eda/gazetteer_analysis.py
```

Для tokenizer-аудита нужны загрузки из Hugging Face или локальный кеш.
PyTorch для самого анализа токенизаторов не требуется. Проверка gazetteer
работает без сети с сохранённым снимком `artifacts/gazetteer_analysis/raw/UZ.zip`.
Флаг `--download` обновляет снимок и может изменить результаты.

## Состав публикации

- `artifacts/style_analysis/`: актуальный прогон Sol low, батчи не более 50,
  первичная разметка, объединённые решения и отчёты согласованности.
- `artifacts/entity_coverage/`: покрытие сущностей обучающим словарём.
- `artifacts/external_ner_analysis/`: аудит внешних NER-корпусов.
- `artifacts/gazetteer_analysis/`: источники, GeoNames, покрытие и ручная проверка.
- `scripts/eda/`: исходные вспомогательные скрипты анализа; при переносе
  адаптированы только пути к корню проекта и данным.
- `scripts/build_gazetteer_section.py`: сборщик раздела 5; его запуск очищает
  выводы этого раздела. Команда: `uv run python scripts/build_gazetteer_section.py`.

Артефакты сохранены как исторический снимок: абсолютные пути в метаданных и
выводах ноутбука могут указывать на исходную рабочую папку. Перезапуск обновляет
соответствующие результаты. Повторный запуск ноутбука не вызывает LLM-разметку:
он читает сохранённые ответы. Наличие скриптов не гарантирует побайтовое повторение
недетерминированных ответов субагентов.

Старый прогон Luna, дублирующий `style_analysis.zip`, локальное окружение,
кеши и аудиофайл не публикуются. Исходные train/dev не дублируются.

## Интерпретация и источники

Покрытие словаря не является NER precision/recall/F1. Примеры из dev для ручной
проверки нельзя автоматически добавлять в обучающий словарь. Эти результаты EDA
не являются модельными экспериментами и не добавляются в `reports/experiments.csv`.

GeoNames и производный словарь имеют атрибуцию в
`artifacts/gazetteer_analysis/README.md`. Условия разных внешних источников
не следует смешивать. Артефакты разметки содержат тексты из исходного корпуса.
