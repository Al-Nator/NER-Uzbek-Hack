## Ограничения

[FAQ](../FAQ.md): финальная машина — одна A100 80 GB; жёсткий production SLA
не установлен. Желательный ориентир — до 5 секунд на запрос с батчем 1–8
сообщений; около 30 сообщений/с — порядок продуктовой нагрузки, не формальный
порог оценки. Таймаут 120 секунд evaluator-а не является допустимым SLA.

## Варианты

| Подход | Стоимость и ограничение |
|---|---|
| s32 отдельно | Текущий quality-reference; HTTP benchmark ещё нужен |
| s24+s32 всегда | Два разных fine-tuned encoder-а; их вычисления нельзя переиспользовать как один encoder без нового обучения |
| Router до моделей | Выбирает только одну модель; не объединяет сущности обеих, возможны ошибки маршрутизации |
| Каскад | s32 всегда, s24 только для отобранных сложных документов; средняя стоимость ниже полного ансамбля, хвост latency остаётся дорогим |
| Общий encoder + головы | Новый multi-task эксперимент, не механическое объединение имеющихся весов |
| Distillation | Ансамбль используется при обучении, один student в сервисе; сохранение прироста нужно измерять |

Router, который сначала вычисляет обе модели, не экономит их inference.
Для каскада ориентировочно T = T32 + p*T24 + overhead, где p — доля fallback;
формула не заменяет замер batching, p95 и конкуренции за одну GPU.
Уверенные пропуски сущностей могут не обнаруживаться простым confidence gate.
Обучаемый gate требует train-holdout/OOF, не обучения по official dev.

## Порядок проверки

1. На готовых predictions проверить дополняемость и выигрыш ансамбля по exact F1.
2. Измерить s32 и ансамбль через HTTP: warmup, batch 1/4/8, короткие/длинные
   документы, p50/p95/p99, documents/s, peak VRAM на целевой A100.
3. Если ансамбль даёт полезный прирост, но не проходит бюджет — проверить простой
   confidence-каскад и кривую F1 против доли fallback; затем обучаемый router.
4. Distillation — отдельный эксперимент для одного быстрого production student.
   Для teacher-разметки использовать разрешённый train/unlabeled, не dev/test.

Пока ни ансамбль, ни router, ни ускорение TensorRT не являются измеренным результатом.
Источник по distillation ансамбля для NER:
[Reich et al., EMNLP 2020](https://aclanthology.org/2020.emnlp-main.450/).
