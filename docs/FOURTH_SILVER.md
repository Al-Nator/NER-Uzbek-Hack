## Данные

Релиз `external_annotation/full_20260906_v1/releases/1788671493493201109`:
5 617 silver-кандидатов, согласованных двумя проходами LLM.
Это не human-validated gold; согласие одной модели не является независимой проверкой.
Пользователь разрешил отдельный исследовательский эксперимент; исходные
`train_eligible=false`, `release_gate` и сведения о непроверенных правах не менялись.
Такой запуск не означает разрешения на публикацию корпуса или production-использование.

Повторный `SimpleLeakage`-аудит исключил 32 совпадения с train и 2 с dev.
Проверяются normalized/lexical exact, общие фрагменты из 10 слов и anchored near-dev.
Это консервативный автоматический фильтр, не доказательство отсутствия всех near-дубликатов.
Осталось **5 583**, включая 1 265 согласованных документов без сущностей.
Источники: uzcrawl 3 055, kknews 400, uznlp_gold 1 942, legal_raw 186.
Изначальная разметка источника uznlp_gold не используется вместо LLM-разметки.

Выборка: `artifacts/series4/external_silver_v1/silver.jsonl`.
Рядом `manifest.json` с SHA-256 входов/выхода и `excluded.jsonl` с причинами.
Исходные тексты и offsets не меняются. Official dev: прежние 1 500 документов.
С полным проверенным Luna-набором (9 827 изменённых копий из s44)
нормализованных lexical exact-дубликатов у принятого silver не найдено.

## Эксперименты

| Run | Train | Проверяемый эффект |
| --- | ---: | --- |
| s45_bge_gp_external_silver | 13 000 + 5 583 = 18 583 | Silver против s32 |
| s46_bge_gp_silver_luna | 13 000 + 5 583 + 9 827 = 28 410 | Luna поверх silver; silver поверх s44 |

Оба стартуют от pretrained **BGE-M3-RetroMAE + GlobalPointer**, не от s32/s44 checkpoint.
Полностью сохранены параметры s32: seed 42, максимум 5 эпох, early stopping 2,
LR 2e-5, warmup 10%, batch 8, BF16, окно 512/128, порог 0.5, без checkpointing.
Источник имеет вес 1; используется обычное объединение документов, без особого sampler.
При фиксированном числе эпох увеличение данных также увеличивает число optimizer steps.
Поэтому абляция не является сравнением при одинаковом вычислительном бюджете.

Не добавляем программный конвертер, MELM или другие внешние наборы.

## Результаты

Оба запуска завершены 2026-09-06; best — эпоха 5, порог GP 0.5.
Все значения ниже — exact-span на исходном official dev (1 500 документов).

| Run / данные | Micro-F1 | Precision | Recall | ORG F1 | NAME F1 | GEO F1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| s32 / train | 0.905954 | 0.911614 | 0.900364 | 0.881842 | 0.915715 | 0.921327 |
| s44 / train + Luna | 0.907456 | 0.910541 | 0.904391 | 0.886578 | 0.917864 | 0.918939 |
| **s45 / train + silver** | **0.909576** | 0.910345 | **0.908807** | 0.885606 | **0.922583** | **0.921688** |
| s46 / train + silver + Luna | 0.905626 | 0.906865 | 0.904391 | **0.886746** | 0.916935 | 0.914317 |

- Silver против s32: **+0.362 процентного пункта F1**, TP +65, FN −65, FP +17.
  Улучшение преимущественно через recall; самый большой классовый прирост у NAME.
- s45 против прежнего лучшего одиночного s44: +0.212 п.п.
  Это новый наблюдаемый лучший одиночный run, но статистическая значимость не проверена.
- Luna поверх silver: **−0.395 п.п.**, TP −34, FP +26.
  ORG почти неизменен; ухудшились NAME и особенно GEO.
  В этой рецептуре дополнительная транслитерация не помогла; это не доказательство,
  что транслитерация бесполезна при другом sampling/обучающем бюджете.
- До 0.91 у s45 остаётся 0.0004245: округление до 91% не означает достижения 0.91.
  Ансамбль s62 (0.912400) остаётся выше; его скорость HTTP не измерена.

Остаточные ошибки s45: 439 missed, 426 spurious, 81 boundary-short,
77 boundary-long, 2 boundary-shift, 49 wrong-label, 54 wrong-label-and-boundary.
ORG остаётся слабейшим классом. Document exact match — 0.674;
false-positive rate на пустых документах — 0.145455 (s46: 0.174545).
Это автоматические категории расхождений с gold, не ручное заключение о качестве gold.

Срезы по письменности **документа**, s32 → s45:
Latin 0.916566 → 0.920244, Cyrillic 0.853720 → 0.869988,
mixed 0.899813 → 0.898504. Улучшение не равномерно по всем срезам.

Сумма train+eval времени пяти эпох: s45 **31.08 мин**, s46 **46.68 мин**.
Это не полный wall-clock: сюда не входят подготовка, сохранение весов и перенос.
Dev loss вырос до 1.2008/1.4550, несмотря на лучший F1 на последней эпохе.
Поэтому простое продолжение обучения не гарантирует прироста; основной кандидат — s45.

## Запуск и артефакты

A100, последовательная очередь s45 → s46, suffix `s4-silver-v1`.
Конфиги: `configs/series/silver_a100.yaml` и `configs/series/silver_luna_a100.yaml`.
Для второго используется `scripts/run_deferred_series.py`, ожидающий PID и start_ticks
первого процесса: не конкурируют за GPU. Если первый завершится ошибкой, независимый
второй всё равно запускается; статус ошибки первого остаётся видимым.

Remote MLflow: `uzner-fourth-series-a100`, UI через localhost:5001.
Оба полных run-каталога возвращены локально; best/last и все файлы manifest
проверены по размеру и SHA-256 2026-09-06. Удалённые оригиналы не удалены.
Импорт в основной локальный MLflow завершён (`FINISHED`):
[s45](http://127.0.0.1:5000/#/experiments/1/runs/efbcbd47e2f949c2a2ba720d897e0943/model-metrics)
— 12 054 точки метрик;
[s46](http://127.0.0.1:5000/#/experiments/1/runs/b1ddbc109bc04460b7df838321a700b5/model-metrics)
— 14 932 точки. Оба добавлены в `reports/experiments.csv`.
Повторный локальный пересчёт из `predictions/dev.jsonl` в точности воспроизвёл
все поля `metrics/dev.json`. 17 тестов silver-подготовки и очереди прошли.

Public leaderboard submission: `artifacts/submissions/s45_public_v1/predictions.jsonl`.
1 000 документов, 4 392 сущности, 150 пустых ответов; только `hash/entities`.
Инференс s45 best, threshold 0.5, без дополнительного обучения и без использования
public test для выбора параметров. В соседнем `predictions.manifest.json` — SHA-256
входа, выхода и manifest исходного run. Данные и submission не публикуются в Git.

Воспроизведение:

```bash
uv run python scripts/predict_jsonl.py \
  --source-run runs/s45_bge_gp_external_silver_s4-silver-v1 \
  --input /путь/к/public_test_inputs.jsonl \
  --output artifacts/submissions/s45_public_v1/predictions.jsonl
```

Перед финальной сдачей допустимо рассмотреть отдельное обучение от pretrained
на train + dev + silver с фиксированными 5 эпохами, если это разрешено правилами.
Это не выполнено: после объединения dev уже не является независимой оценкой,
и такое обучение не следует путать с ещё пятью эпохами продолжения s45.
Каждый run: `runs/<run_id>/`, метрики в `logs/events.jsonl`, best/last checkpoints.
Локальные watch-сервисы возвращают каждый завершённый run и импортируют лёгкие
артефакты/метрики в `uzner-first-series`; веса остаются в runs, не дублируются в MLflow.

Подготовка воспроизводится командой (выход должен ещё не существовать):

```bash
uv run python scripts/prepare_silver_experiment.py \
  --release artifacts/external_annotation/full_20260906_v1/releases/1788671493493201109 \
  --output artifacts/series4/external_silver_v1 --research-authorized
```
